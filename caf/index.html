New train names (bracket and state)

The bracket and state of a train are the ones its name has always had in the morning CAF message (RBL is (LOK) Uttar Pradesh, GAR/BZU is (NAG) Madhya Pradesh). A name that is new gets the sheet's DEST ZONE for its bracket, and the state of its station from the station list; a station the list does not have gets the state its zone mostly serves (CR is Maharashtra, SER is West Bengal), so check it in the table. To fix a name for good, add it here, one on a line, as NAME = State (for example BCNE = Maharashtra), or NAME = BRACKET, State to set the bracket too. It is remembered on this device.
